Bash скрипты для работы ИЗВНЕ контейнеров

Docker:
sudo docker ps - посмотреть запущенные контейнеры
sudo docker compose up -d - собрать контейнеры из docker-compose.yml
sudo docker compose down -v - остановить все контейнеры
sudo docker stop fastapi_db fastapi_app frontend_app - остановить контейнеры
sudo docker rm -f fastapi_db fastapi_app frontend_app - удалить контейнеры
sudo docker logs -f fastapi_app - выводить логи из контейнера
sudo docker system prune -a --volumesв - удалить ВСЕ

Alembic:
sudo docker compose exec api alembic revision --autogenerate -m "comment" - создать ревизию
sudo docker compose exec api alembic upgrade head - применение всех последних ревизий
sudo docker compose exec api alembic downgrade -1 - возврат на одну версию назад
sudo rm -f src/common/database/alembic/versions/* - удалить все ревизии (таблицы из БД нужно удалить вручную)

Bash скрипты запуска (превратить в исполняемый файл:
cp .env.example .env
sudo docker compose up -d
docker logs -f fastapi_app

API доступен по адресу http://localhost:8000/docs
клиентский фронтенд-сервер доступен по адресу http://localhost:5500
подключиться к БД можно через хост localhost и порт 5433

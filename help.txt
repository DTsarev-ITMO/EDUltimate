Docker:
sudo docker ps - посмотреть запущенные контейнеры
sudo docker compose up -d - собрать контейнеры из docker-compose.yml
sudo docker compose down -v - удалить все контейнеры
sudo docker stop fastapi_db fastapi_app - остановить контейнеры
sudo docker rm -f fastapi_db fastapi_app - удалить контейнеры
sudo docker logs -f fastapi_app - выводить логи из контейнера


Alembic:
alembic revision --autogenerate -m "comment" — создание скрипта на основе изменений в моделях
alembic upgrade head — применение всех последних миграций
alembic downgrade -1 — возврат на одну версию назад

bash скрипты запуска:
cp .env.example .env
sudo docker compose up -d
docker logs -f fastapi_app

sudo docker compose exec app alembic revision --autogenerate -m "Initial revision" - создать ревизию
sudo docker compose exec app alembic alembic upgrade head - применить последние ревизии

sudo docker system prune -a --volumes - удалить ВСЕ


API доступен по адресу http://localhost:8000/docs
клиентский фронтенд-сервер доступен по адресу http://localhost:5500
подключиться к БД можно через хост localhost и порт 5433

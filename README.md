Мой маленький пет-проект Eating Desorder Ultimate - приложение для контроля питания и прогресса похудения/набора массы на основе FastAPI и PostgreSQL.

Реализовано:
1. Проект на GitHUB
2. RESTfull API для работы с базой данных БЖУ продуктов

В процессе:
1. Написать RESTfull API для работы с базой данных пользователей

Планы:
1. Написать RESTfull API для работы с базой данных пользовательских рецептов
2. Обеспечить безопасность базы данных
3. Обеспечить возможность удаленного доступа к API, вывести бэкенд и базу данных на сервер
4. Наполнить базу данных
5. Написать фронтенд для ПК
6. Реализовать алгоритмы составления диеты
7. Реализовать инфографику прогресса пользователя
8. Написать фронтенд для смартфонов на базе андроид и iOS

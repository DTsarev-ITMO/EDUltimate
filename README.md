Мой маленький пет-проект Eating Desorder Ultimate - приложение для контроля питания и прогресса похудения/набора массы на основе FastAPI и PostgreSQL.

Реализовано:
1. Проект на GitHUB
2. RESTfull API для работы с базой данных БЖУ продуктов
3. RESTfull API для работы с базой данных пользователей: аутентификация и роли
4. Все в Docker котнейнерах
5. Простенький фронтенд в браузере
6. Реализован парсер данных о БЖУ продуктов со стороннего сайта
7. Реализованы стартовые скрипты

В процессе:
1. Обновить логику регистрации и аутентификации
2. Реализовать алгоритмы составления диеты
3. Написать эндпоинты для пользователей и диет

Планы:
1. Обеспечить безопасность базы данных
2. Обеспечить возможность удаленного доступа к API, вывести бэкенд и базу данных на сервер
3. Заменить парсер обращением к внешнему API
4. Написать RESTfull API для работы с базой данных пользовательских рецептов и рационов 
5. Реализовать инфографику прогресса пользователя
6. Написать фронтенд для смартфонов на базе андроид и iOS




Инструкции по запуску проекта:
1. Клонируйте проект:                                 git clone https://github.com/DTsarev-ITMO/EDUltimate
2. Переименуйте .env.example в .env:                  cp .env.example .env
3. Запустите скрипт run.sh
4. Чтобы остановить проект, запустите скрипт stop.sh

После сборки и запуска контейнеров доступ к ним следующий:
1.  API доступен по адресу http://localhost:8000/docs
2.  клиентский фронтенд-сервер доступен по адресу http://localhost:5500/frontend/
3.  подключиться к БД можно через хост localhost и порт 5433

Так же см. help.txt.

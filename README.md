Мой маленький пет-проект Eating Desorder Ultimate - приложение для контроля питания и прогресса похудения/набора массы на основе FastAPI и PostgreSQL.

Реализовано:
1. Проект на GitHUB
2. RESTfull API для работы с базой данных БЖУ продуктов
3. RESTfull API для работы с базой данных пользователей: аутентификация и роли

В процессе:
1. Написать RESTfull API для работы с базой данных пользовательских рецептов и рационов

Планы:
1. Обеспечить безопасность базы данных
2. Обеспечить возможность удаленного доступа к API, вывести бэкенд и базу данных на сервер
3. Наполнить базу данных
4. Написать фронтенд для ПК
5. Реализовать алгоритмы составления диеты
6. Реализовать инфографику прогресса пользователя
7. Написать фронтенд для смартфонов на базе андроид и iOS
